Yarn Patch功能使用

第一步执行 Yarn 官方补丁命令

在项目根目录下，直接运行 Yarn 的原生补丁提取命令：
以react-native-permissions为例:
1yarn patch react-native-permissions
2
运行后，终端会打印出一段提示，里面包含一个临时的文件夹路径，类似于：
    You can now edit the following folder: /private/var/folders/.../user/react-native-permissions-8f3a12

第二步去那个临时文件夹里修改代码

第三步 提交并生成永久补丁

回到你原本的项目终端，运行以下命令，后面跟上刚才终端给你的那个临时文件夹路径：
1yarn patch-commit -s 第一步生成的文件夹目录
2
运行成功后，高版本 Yarn 会自动做两件事：
  • 会在你的项目根目录下自动创建或更新 .yarn/patches/ 文件夹，并在里面放入规范的补丁。
  • 会自动把补丁的引用关系写入到项目根目录的 package.json 中的 "resolutions" 字段里。
最后，照常执行 yarn install
