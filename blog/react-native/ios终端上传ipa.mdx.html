ios终端xcrun上传ipa文件

背景

打包mac没有登陆开发者账号，没有办法使用xcode的自动上传，只能使用终端上传ipa文件

步骤

  1. 打开App Store Connect,
  2. 进入用户和访问
  3. 选择集成
  4. 点击+添加新的密钥，该步骤会生成 Issuer ID 和 密钥 ID
  5. 下载 *.p8文件放在 当前用户/private_keys下面
  6. 使用 Issuer ID 和 密钥 ID进行上传
        xcrun altool --upload-app --type ios -f *.ipa --apiKey 密钥ID --apiIssuer IssuerID
