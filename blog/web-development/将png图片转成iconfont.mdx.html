使用SVG生成Iconfont

访问Fontello，选择 Fontello 提供的内置图标，或者通过SVG上传 自己的图标,生成之后下载

项目中使用生成的icon内容

  1. 把字体文件（如 woff, ttf, eot 等）和 CSS 文件 上传到你的项目中（例如放到 fonts 和 css 文件夹下）。
  2. 在CSS 文件中，通过 @font-face 引用字体文件，并使用类选择器来显示图标。例如
    1@font-face {
2    font-family: 'iconfont';
3    src: url('fonts/iconfont.eot');
4    src: url('fonts/iconfont.eot?#iefix') format('embedded-opentype'),
5        url('fonts/iconfont.woff2') format('woff2'),
6        url('fonts/iconfont.woff') format('woff'),
7        url('fonts/iconfont.ttf') format('truetype'),
8        url('fonts/iconfont.svg#iconfont') format('svg');
9}
10
11/* 图标样式 */
12.icon {
13    font-family: 'iconfont';  /* 引用字体 */
14    font-style: normal;
15    font-weight: normal;
16    speak: none;
17    display: inline-block;
18    text-decoration: none;
19    text-align: center;
20    line-height: 1;
21}
22
23/* 示例图标 */
24.icon-home:before {
25    content: "\e600";  /* 使用生成的 Unicode 字符 */
26}
27
  3. 在 HTML 文件中使用图标
    1<i class="icon icon-home"></i>
