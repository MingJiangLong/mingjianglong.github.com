# 简易工具包上包过审方案

## 背景

    **打包**和**提包**两成分别在不同的设备上来进行。打包机不再登陆开发者账号，提审机登陆开发者账号。
    因为打包机没有开发者账号所以没办法打包自动签名，所以打包需要我们手动签名；同样上传至appStore时需要去appStore生成p8文件才能上传。

### 打包流程

    1. 在打包机mac电脑生成钥匙串
    
    2. 在提审机创建app 并用该钥匙串生成一个 .cer文件和一个*.mobileprovision文件，并将该文件访问打包机**双击执行**

    3. 打包机选择*.mobileprovision文件，并打包

### 上传流程
 
    1. 提审机生成一个文件（App store 用户和访问）会生成 apiKey和issuer用于上传
    2. 将该文件放回打包机 需要特定目录 `用户根目录/private_keys/`, `shift`+`command`+`H`可以快速去用户根目录
    3. 执行以下代码上传ipa至app store

        ```bash
            xcrun altool --upload-app --type ios -f *.ipa --apiKey xxxxxx --apiIssuer xxxxxxxxxxx
        ```
