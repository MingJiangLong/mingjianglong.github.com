# RN开发常用命令

### 项目初始化

    ```shell
        npx @react-native-community/cli@latest init demo
    ```

### 网络相关

- ios查看ip地址
    ```shell
        ifconfig
    ```

### adb相关

- adb查看连接的设备
    ```shell
        adb devices
    ```

- abd打开RN开发者菜单
    ```shell
        adb shell input keyevent 82
    ```
