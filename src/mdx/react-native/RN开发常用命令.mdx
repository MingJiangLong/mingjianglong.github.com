# RN开发常用命令

### 项目初始化
- 初始化RN项目
    ```bash
        npx @react-native-community/cli@latest init demo --version 0.81.5
    ```
### adb相关

- adb查看连接的设备
    ```shell
        adb devices
    ```

- abd打开RN开发者菜单
    ```shell
        adb shell input keyevent 82
    ``` 
- Android 设备和开发者的机器之间创建端口转发。
    ```shell
        adb -s 设备id reverse tcp:端口 tcp:端口
    ``` 
- 查看芯片架构
    ```shell
        adb shell getprop ro.product.cpu.abi
    ```
