# RN开发问题汇总


- **react-native-select-contact**相关
    1. Cannot open the contact selector twice

    添加queries相关代码 如下:

    ```xml:AndroidManifest.xml

        <manifest >
            <application></application>
            <queries>
                <intent>
                <action android:name="android.intent.action.VIEW" />
                <category android:name="android.intent.category.DEFAULT" />
                <data android:mimeType="vnd.android.cursor.dir/contact" />
                </intent>
            </queries>
        </manifest>
    ```

- unable to initiate PIF transfer session (operation in progress?)

    移除文件 **~/Library/Caches/org.swift.swiftpm**
    ```shell
        rm -rf ~/Library/Caches/org.swift.swiftpm
    ```
- A problem occurred starting process 'command 'npx'

    如果本地有正确配置node，那大概率是Android Studio 的Gradle JDK问题。
    检查 `Setting`->`Building`,`Executing,Deployment`->`Build Tools`->`Gradle`->`Gradle JDK`是否正确，按照RN官网配置，我们应该选择`Zulu17.0.12`相关
